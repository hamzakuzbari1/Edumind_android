EDUMIND PRODUCT DESIGN

Global Mobile UI Benchmark

02 · Executive summary

What the four Homes actually do

EduMind Home must answer four questions: what to do now, what needs attention, what is happening today/this week, and how I am progressing. None of the four apps solve all four. Each is strong at one job.

Khan Academy

Calm catalog + mastery. Next action appears inside a course (Mastery Challenge), not as a student-day dashboard. Hierarchy is excellent. Habit, planner, and AI chat are weak or missing on mobile.

Coursera

Best Continue Learning card: course, module, percent, duration, Play. Home/Learn is still a course list. Discovery and certificates dominate store creative. EduMind must not copy this as Student Home.

Duolingo

Best next action in the world: one START node on a path. Streak, XP, and leagues create habit. Aesthetic is cartoon. Borrow the principle, not the owl.

Upwork

Professional density, scanning, messaging, and a named AI (Uma) with a single insert CTA. Not a learning Home — use it for cards, nav, and AI semantics.

Limitation: App Store creatives often frame production UI inside marketing art (angled phone, slogan). They are still official store screenshots of current iOS listings (accessed 5 Sep 2026). Duolingo path Home is documented with official blog UI from 2022 (path launch) and Feb 2026 (core tabs refresh).
03 · Khan Academy

Browse hierarchy — calm education, not a dashboard

Khan’s top-level mobile job is find a subject. Search + Filter + a chevron list. “Surprise me!” is the only playful CTA. This is catalog UX. EduMind should keep this pattern in موادي, not on الرئيسية.

Official App Store
Browse / Search · iOS listing v8.5.1 · 13 Aug 2026
Source: apps.apple.com/us/app/khan-academy/id469863705

1Search first. Discovery is a tool, not a feed.

2One-column list. Math → Science → Economics. Icons are optional; chevrons do the work.

3Whitespace is the brand. Few colors, lots of air. Feels like a textbook, not a marketplace.

4Missing for EduMind: greeting, today, streak, tutor, messages. Khan Home is not a student OS.

Borrow: subject list density and quiet type for موادي and lesson trees.
04 · Khan Academy

The closest Khan gets to “what now?”

Inside 5th grade Math, Khan puts a Mastery Challenge card above the unit list. That is their next-mission pattern. Progress is mastery points, not a streak flame.

Official App Store

1Context bar: Math · 5th grade. Always know where you are.

2Mastery Points 17%. Quantitative progress at course level.

3Get started is the only primary button. One next action.

4Unit → lesson list under the CTA. Hierarchy Course → Unit → Lesson.

5Bottom nav: Home · Explore · Bookmarks. Three destinations. Simple.

Khanmigo chat is not in the Khan Academy app. Official Help: Activities only in-app v8.0+; full tutor is mobile web. Do not cite a Khanmigo chat screenshot as native app UI.
05–06 · Khan Academy · lesson

Lesson: one problem, then Up next

Official App Store Exercise — one question, Check disabled until pick, hint FAB.
Official App Store Video lesson — player + Bookmark/Share/Transcript + Up next playlist.

UX takeaway: Decision fatigue is killed by showing one problem. Sequence is shown as “Up next”, not as a catalog. EduMind lessons should feel this calm. Keep AI as a cyan assist, not a second lesson type competing on the same row.

07 · Coursera

Store Home is a career marketplace. Learn is a course list.

Coursera’s official iOS creatives sell experts, certificates, and career paths. That is the pattern EduMind Student Home must avoid. The useful screen is “All Courses / Start Today”: resume + progress + Play.

Official App Store

apps.apple.com/us/app/coursera-grow-your-career/id736535961

1Title is “All Courses”. This is My Learning, not a day OS.

2Hero card: Google UX certificate, Course 2 of 5, 60%, current lesson “Prototyping with Figma”, 6 min, Play.

3Time-to-start next to Play reduces friction. EduMind should show minutes left on المهمة التالية.

4Secondary course uses “Get Back Into It” ghost button. One primary, others quieter.

Avoid on الرئيسية: partner logos, career-path catalogs, certificate grids, “Learn with experts”. That lives in استكشف / subscriptions, not Student Home.
08–10 · Coursera

Lesson tools vs catalog chrome

Official App Store Lesson player — video + Notes / Transcript / Attachments tabs.
Official App Store Career Path — marketplace hierarchy. Do not use as Home.
Official App Store Languages sheet — settings in a sheet, not a pushed jungle.

Borrow: continue-learning anatomy (provider, % , lesson name, duration, one Play). Borrow: sheets for settings/language. Avoid: Home as discovery. Coursera Help Center also names a dedicated Learn tab for enrolled programs — catalog is a different surface.

11 · Duolingo

Home = one START. That is the whole product.

Official Duolingo blog (May 2022 / path live 1 Nov 2022) documents the current Home architecture: a vertical path, one highlighted node, START. Feb 2026 core-tabs post shows the same path still in production with refreshed tabs.

Official blog · 2022
Old skill tree → new learning path
blog.duolingo.com/new-duolingo-home-screen-design/

1Decision fatigue. Old Home: many skill circles. New Home: one START.

2Unit header answers “what am I learning?” — “Use basic phrases, greet people.”

3Locked future is visible but not tappable. Path, not menu.

4Top stats: flag, streak, gems, hearts. Motivation without a dashboard essay.

Borrow for المهمة التالية: one obvious node, one verb, everything else secondary. Do not borrow the winding cartoon path or mascot.
12 · Duolingo

2026 tabs: Home still owns next action; other tabs own motivation

Official blog · Feb 2026 Home path · Quests · League · Video call · Profile · Feed — blog.duolingo.com/core-tabs-redesign/

Home is not where leagues, quests, and feed live. EduMind should likewise keep XP/streak as a snapshot on الرئيسية, and push leagues-style social (if ever) off Home. Video-call AI is a dedicated tab with a single CALL +XP CTA — named character, one action.

13–14 · Duolingo

Lesson micro-UX and streak, without copying the owl

Official App Store Lesson v7.138.0 · 2 Sep 2026 — one task, progress bar, energy, Check.
Official App Store Streak recap — huge 3, week dots, one orange CTA.
Official App Store Courses list — subjects off the path. EduMind: موادي / اللغات.
Do not copy: cartoon bodies, lowercase slogans on giant candy buttons, hearts-as-punishment, leagues as the emotional core of Home. Do copy: one task per screen, visible lesson progress, streak as a small amber chip.
15 · Upwork

Professional scanning, not education

Upwork is here for density, messaging, and AI-in-a-task. Home is not a learning dashboard.

Official App Store Reports Overview v2.12.0 · 26 Aug 2026 — label / big number / chevron rows.

1Scanable rows. Work in progress, In review, Pending, Available. EduMind progress snapshot can be this dense.

2Color is labels, not decoration. Green type, black numbers, grey chevrons.

3One tap to detail. Summary never dumps the full ledger on Home.

Borrow: compact metric list for المستوى / XP / اختبار / أيام الدراسة. Not a four-color infographic.
16–18 · Upwork

Messages, projects, named AI

Official App Store Messaging room — names, time, @mention, file cards, call + attach.
Official App Store Project / milestone — primary Pay now, status pill, timeline.
Official App Store Uma AI — chat in the task, then Insert cover letter.

AI rule from Uma: assistant has a name/mark, lives inside the job, produces an insertable artifact, one green CTA. EduMind AI Tutor should be cyan, task-bound (explain this quiz / plan this session), never a second Home feed.

22 · Borrow

What EduMind should learn

Khan Academy

  • Course → unit → lesson tree
  • Whitespace, serif/sans mix for lesson titles if needed — or Cairo only, but keep air
  • One Check / Get started per screen
  • 3-item bottom nav as a ceiling for “primary jobs”

Coursera

  • Continue card: title, step “3 of 8”, %, minutes, Play
  • Ghost button for secondary courses
  • Sheets for language / settings
  • Transcript/notes adjacent to player

Duolingo

  • One START / المهمة التالية above the fold
  • Lesson = one prompt
  • Streak as a tiny amber signal
  • Motivation tabs ≠ Home

Upwork

  • Metric rows + chevron
  • File/message cards
  • Named AI + Insert CTA
  • Status pills (قادم / يحتاج متابعة)
23 · Avoid

What EduMind should not become

Not Coursera Home

No partner logo walls, career paths, or certificate mosaics on الرئيسية. Catalog belongs in موادي / استكشف / الاشتراكات.

Not Duolingo skin

No owl, no candy path, no 6 equally loud tabs of games. No hearts that punish studying. EduMind is school-grade, indigo, Cairo, RTL.

Not Khan-only catalog

A browse list does not tell a Syrian 11th-grader what to do at 6:30pm. Khan has no Routine, Planner, or parent loop.

Not Upwork feed

Do not pack Home like a job list. Density is for snapshots and messages, not for 12 competing CTAs.

24 · Recommended architecture

EduMind Student Home hierarchy

Not an LMS Home. A daily operating system. Terminology matches current product (ST01).

  1. Top bar: الرئيسية · bell (notifications) · avatar → حسابي. Optional streak flame (amber) as icon, not a banner.
  2. Greeting: صباح الخير، رنا + one-line context (صف / مستوى).
  3. المهمة التالية (Next Mission): Dominant card. Subject, lesson name, minutes left, درس 3 من 8, PrimaryButton متابعة الدرس. Locked state → الاشتراكات. This is Duolingo START + Coursera Play.
  4. اليوم / هذا الأسبوع: Max 3 planner rows + routine signal. Ghost افتح المخطط. Differentiator vs all four apps.
  5. يحتاج انتباهك / توصية EduMind: One cyan-marked card. Weak topic, bad quiz, missed routine, upcoming exam. Never more than one recommendation.
  6. تابع التعلم: Only if different from Next Mission. Else omit.
  7. Progress snapshot: Level, XP to next, streak days, last quiz %. Upwork-style rows.
  8. لمحة المواد: 2–3 subject chips + “الكتالوج في موادي”. Khan browse does not live here.
Above the fold (first screen): top bar + greeting + Next Mission + maybe the first Today row. Everything else scrolls. Maximum two major cards before scroll.

Visual rules

  • Indigo = primary action only once per screen
  • Cyan border = AI / توصية, never a second primary button
  • Amber = streak/XP only
  • Green = routine / success
  • ~18dp radius, white cards, light grey canvas
  • RTL: numbers stay, chevrons flip, greeting on the right

Bottom nav is the product map. Home does not repeat موادي as a grid.

26–28 · Compose-ready rules

Mobile UX rules for Jetpack Compose

Layout

  • One dominant next action above the fold. Use PrimaryButton once.
  • Max 2 major EduCards before first scroll; 3 planner rows max.
  • Section spacing = existing Spacing.section; do not tighten to Upwork density on Home.
  • Card density: Home medium; موادي can be tighter lists (Khan); messages can be denser (Upwork).

Navigation

  • Keep student tabs: الرئيسية · روتيني · اللغات · مشاريعي · موادي · حسابي. Do not add a 7th “Discover” tab on Home.
  • Drawer/hamburger: secondary only (settings, parent link, legal). Not primary IA.
  • Notifications: top-bar bell + badge. Messages: dedicated entry in حسابي or a badge, not a Home module of threads.
  • Sheets: language, filters, “why this session”, AI short assist. Pushed screens: lesson, quiz, course, chat thread.

AI

  • Cyan AiMarker + one recommendation card. Uma pattern: produce an action (open lesson / insert plan), not an essay.
  • Do not put a chat composer on Home.

Progress / RTL

  • XP/streak as compact snapshot; achievements preview can sit below, not compete with Mission.
  • RTL: Arrangement respects layout direction; linear progress mirrors; numerals use existing numeral helper.
29 · Principles

Final design principles

  1. Home is a mission, not a mall.
  2. One verb. متابعة الدرس / ابدأ / راجع. Everything else is ghost or text.
  3. School-grade visual. Indigo, white, 18dp, Cairo. Cyan only for real AI.
  4. Today is our wedge. Planner + Routine do not exist on the four benchmarks. Protect them.
  5. Catalog has a house. موادي. Home only snapshots.
  6. Motivation is amber dust, not a game OS.
  7. Cite production UI. This PDF prefers App Store + official blogs. Marketing frames are labeled.

Research only. No Android / Gradle / Kotlin changes were made.
